# 秘書検定 暗記カード - 2級3級の敬語と作法

秘書技能検定 3級・2級の対策に特化した、iOS向け暗記カードアプリ。
敬語・言葉遣い、来客・接遇・マナー、文書・慶弔・事務の3科目・計320枚のカードを、
段階ヒント（図解 → 語呂合わせ → 3択）＋想起練習＋間隔反復（忘却曲線）で反復学習できる。

`~/Projects/otsu4-card`（乙4暗記カード）のSwiftUI / SwiftData / StoreKit2エンジンを複製し、
デッキの内容・科目定義・アプリ内文言を秘書検定向けに全面的に書き換えたもの。

## この資格ならではの設計

秘書検定は知識の暗記よりも「場面で正しい行動を選べるか」を問う試験のため、カードの作り方を一般の資格アプリと変えている。

- 問題文は具体的な場面（電話応対・来客対応・上司への確認など）から始める
- `choices`（誤答）の作り込みを重視した。「一見正しそうだが、実は失礼にあたる／秘書の職分を超えている」誤答
  （上司の予定を無断で外部に伝える、上司に確認せず独断で判断する、過剰な二重敬語など）を中心に据えている
- 敬語では二重敬語・尊敬語と謙譲語の取り違えを重点的に扱う（「二重敬語・敬語の誤用」トピックに20枚）
- 慶弔の金額相場は地域・関係性で幅があるため、`source`で「一般的には」と明示し、断定を避けている

## 技術構成

- SwiftUI / SwiftData / StoreKit2、iOS 17.0+、iPhone専用（TARGETED_DEVICE_FAMILY "1"）
- xcodegen（`project.yml`）でXcodeプロジェクトを生成
- 完全オフライン・アカウント不要・広告なし・データ収集なし、4+レーティング
- 学習方式: 段階ヒント（図解 → 語呂合わせ → 3択）＋想起練習＋間隔反復（忘却曲線）
- 課金: 無料DL＋買い切り¥1,480（`com.goonobu.hishocard.unlock`）。月額サブスクは作らない方針
- 無料枠: 最初の3トピック（敬語・言葉遣いの「尊敬語の基本」「謙譲語の基本」「丁寧語と言葉遣いの基本」、計40枚）＋1日20枚まで

カードのスキーマ（`id / subject / topic / question / answer / choices[3] / hintImage{template,params} / goro / goroNote / source / tags`）は
otsu4-cardの`CardDefinition.swift`をそのまま流用し、変更していない。
図解ヒントのテンプレートは既存15種のうち `signboard`（用語・表書き）・`gradeBadge`（金額・段階の判断）・
`calendar`（日程・予定管理）・`structure`（組織・文書構成・作法の分類）・`personnel`（人・席次・役割）の
5種を中心に、内容に合うものを選んで使用しており、新しいテンプレートは追加していない。

## 内容の正確性について

過去に他アプリの既存カードから外部AI校閲で13件の誤りが発見された反省を踏まえ、以下を徹底している。

- 確実に正しいと言える内容だけを書き、曖昧な記憶で数値や慣習を断定しない
- `source`に根拠（出題範囲の区分・一般的なマナーとしての性質など）を明記する
- 金額相場やお札の向きなど、地域・宗派・時代で幅がある事項は「一般的には」「〜とされる」と明示し、断定しない
- 席次は「一般的な原則であり絶対の規則ではない」ことをカード自体でも明示している

## ビルド・検証

```bash
xcodegen generate
xcodebuild build -scheme HishoCard -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO
python3 production/validate_deck.py
```

`production/validate_deck.py`は、Swiftのビルドとは独立にデッキJSONを検証する自己チェックスクリプト。
id重複ゼロ・choicesちょうど3件（重複なし・answerを含まない）・hintImage.templateが既存15種のいずれか・
カード総数が仕様320枚の±10%以内（288〜352枚）であることなどを確認する。

## 開発時の制約（このリポジトリの作成経緯）

このアプリはシミュレータを起動せず、`xcodebuild build`によるビルド確認までで検証を止めている
（別プロジェクトがシミュレータを使用中だったため）。App Store Connectへの登録・アップロード・
審査申請は一切行っていない。ProductID（`com.goonobu.hishocard.unlock`）はコード内定義のみで、
ASCには未登録の状態。
